# このツールが自動化しないこと(Xの規約対策)

X(旧Twitter)の自動化ルール・スパムポリシーに抵触するリスクがあるため、
以下は本ツールの対象外にしている。実装を追加する場合も、この方針は
変えないこと。

## 自動化しない行為

- **DMの自動一斉送信**: 見知らぬ相手への定型文の自動送信は、規約上の
  スパム行為(unsolicited bulk messages)に該当しうる。`dm_assist` は
  下書きの生成のみを行い、送信は必ず人間が手動で行う。
- **自動フォロー/自動アンフォロー**: フォロワー数を機械的に増やす目的の
  自動フォロー・アンフォローの繰り返しは規約違反。
- **自動いいね/リポストによる水増し**: エンゲージメントの見かけ上の水増しは
  行わない。
- **投稿の完全自動化(現時点)**: X APIが未接続の間は、投稿そのものも
  人間が手動で行う。将来API接続後に自動投稿を実装する場合も、内容は
  必ず人間の承認(`autox content approve`)を経たものに限定する。

## 複数アカウント運用について

このツールは現時点で1アカウント運用を前提に設計している。複数アカウントを
同一の仕組みで運用する場合、Xの複数アカウントポリシー(相互のなりすまし、
同一内容の重複投稿、投票操作等の禁止)に追加で注意が必要になる。

## なぜ「欺瞞的な演出」を採用しなかったか

参考にした情報源には、他人とのやり取りのスクリーンショットを実績として
流用する手法が含まれていたが、本ツールでは採用していない。相手を騙す
行為であり、トラブル時の悪評拡散リスクを高めるほか、なりすまし・虚偽表示に
関する規約違反にもなりうるため。詳細は `docs/account_strategy.md` を参照。
