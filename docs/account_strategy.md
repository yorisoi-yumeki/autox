# アカウント設計ガイド(プロフィール・固定ポスト)

このガイドは「正直な自己開示」を前提にしている。参考にした情報源には
他人の実績を装う演出(DMスクリーンショットの転用等)や、身分を偽う手法が
含まれていたが、それらは意図的に採用しない。理由は2つ:

1. 相手を騙す行為であり、トラブル・悪評拡散のリスクが高い
2. Xの規約(なりすまし禁止)に抵触しうる

## アイコン・ヘッダー

- アイコンは実写・実在の自分を使う。顔出しに抵抗があるなら、後ろ姿や
  雰囲気が伝わる写真、印象の良い私物の写真などでよいが、「別人になりすます」
  ことはしない。
- ヘッダーに「他人とのやり取りのスクリーンショットを実績として貼る」演出は
  推奨しない。代わりに、雰囲気や趣味が伝わる写真、価値観を一言で表すような
  デザインなどを検討する。

## プロフィール文

含めるとよい要素(すべて事実ベース):
- 大まかな活動エリア(都市部/地方 程度の粒度。個人特定できる粒度は避ける)
- 雰囲気が伝わる一言(身長・体型に触れる場合も、事実を書く。不利な情報を
  隠すのは自由だが、聞かれて答える内容と矛盾させない)
- どんな話題で発信しているか(恋愛観、日常、趣味 等)
- どんな相手と繋がりたいか(config/settings.yaml の matching_criteria と
  一致させておくと、生成されるDM下書きともズレなくなる)

## 固定ポスト

- 雰囲気・趣味・大事にしている価値観が伝わる投稿を1〜数件、固定にする。
- 実際に会えた「実績」を誇示する目的の投稿(暗示的なものも含む)は作らない。
  代わりに、価値観や人柄が伝わる投稿(profile/questions.py のインタビュー
  回答をベースにすると一貫性が出やすい)を選ぶ。

## 運用の一貫性について

`autox profile interview` で作った `config/profile.yaml` は、投稿下書き・
DM返信下書きの両方のグラウンディング情報として使われる。プロフィール文・
固定ポスト・日々の投稿・DMでの受け答えが、実際に会ったときの本人と大きく
乖離しないよう、この価値観プロフィールを定期的に見直し、実態と合わせて
アップデートすることを推奨する。
